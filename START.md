## Где главное
- `src/data/views/*.json`: все виды и отели. Новый вид = новый файл по образцу.
- `data/view-candidates.json`: список мест для будущих видов (см. выше).
- `src/data/links.json`: куда ведут кнопки цен. `src/data/site.ts`: почта, соцсети, подписка.
- `data/accounts.json`: метка (subid) и короткий адрес каждой соцсети; `scripts/lib/accounts.mjs` строит из них ссылки профиля и постов (`postLink`).
- `scripts/`: `build-go.mjs` (переходы `/go/`), `fetch-photos.mjs` (фото), `check-site.mjs` (проверка), `make-og.py` (картинка для ссылок), `make-social.py` (аватар и обложки в `brand/social/`).
- `CLAUDE.md`: правила и дизайн. `docs/decisions.md`: решения. `docs/partners.md`: партнёрки. `docs/log-2026-10-18.md`: итог дня простым языком (что сделано, что ждёт, что дорого, ограничения среды).

## Как запускать
- `npm install`, потом `npm run build` и `npm run check:site`. Посмотреть локально: `npm run dev`.
- На GitHub: Actions → «Deploy to hosting» → Run workflow (запустить выкладку вручную).
